    Ou avec une clé API Anthropic

    Nécessaire pour analyser tes photos. Elle est enregistrée uniquement sur cet appareil, et envoyée seulement à l'API d'Anthropic. Elle n'est jamais publiée sur GitHub.

    Comment obtenir une clé ?
    1. Crée un compte sur console.anthropic.com.
    2. Ajoute un peu de crédit (Billing). L'API est payante à l'usage : environ 10 à 20 centimes par analyse, séparément de l'abonnement Claude.ai.
    3. Va dans Settings → API Keys → Create Key, puis colle la clé ici.
