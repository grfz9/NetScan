Photographie ton réseau

Switch, routeur, écran de config ou schéma de TP : NetScan te montre le schéma, les ports, la configuration et ce qui manque pour que ça marche.

Tu peux ajouter jusqu'à 10 photos : la façade de chaque équipement, l'arrière, l'écran de config, le schéma du TP…

  1. Envoi de la photo
  2. Observation de l'image
  3. Identification des équipements et des ports
  4. Tracé du schéma réseau
  5. Lecture / écriture de la configuration
  6. Diagnostic : est-ce que ça fonctionne ?
  7. Rédaction des explications

Clé API Anthropic

Nécessaire pour analyser tes photos. Elle est enregistrée uniquement sur cet appareil, et envoyée seulement à l'API d'Anthropic. Elle n'est jamais publiée sur GitHub.

Comment obtenir une clé ?
  1. Crée un compte sur console.anthropic.com.
  2. Ajoute un peu de crédit (Billing). L'API est payante à l'usage : quelques centimes par analyse, séparément de l'abonnement Claude.ai.
  3. Va dans Settings → API Keys → Create Key, puis colle la clé ici.
